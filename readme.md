# GVP - Gestión de Visibilidad de Parqueaderos (V4)

**GVP** es una solución tecnológica diseñada para la gestión, monitoreo y optimización de la visibilidad de espacios de parqueadero en tiempo real. Este sistema permite integrar dispositivos IoT, sistemas de matriz de ocupación e interfaces interactivas para mejorar el flujo vehicular y la experiencia del usuario.

---

## ⚙️ Características Principales

1. **Monitoreo en Tiempo Real:** Visualización gráfica e isométrica de los espacios libres y ocupados.
2. **Diseño Responsive:** Interfaz adaptable a pantallas de escritorios, tablets y dispositivos móviles.
3. **Integración con Hardware:** Compatible con sensores de presencia, cámaras LPR y dispositivos de control de acceso.
4. **Visualización de Planes:** Interfaz dedicada (`planes.html`) para la gestión comercial y suscripciones del sistema.
